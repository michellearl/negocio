# Michelle Dietetics and Transformation

Landing page developed as a web development training project. It presents the personalized nutrition services of "Michelle Dietetics and Transformation", with presentation sections, a diet gallery, client reviews, and a contact form.

## 🎯 Project Goal

- Practice layout with **HTML5** and **CSS3**.
- Implement interactivity with **JavaScript** (tabs, lightbox, form validation, modal, etc.).
- Apply basic concepts of **responsive design** and **accessibility**.

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (vanilla)
- Google Fonts
- AOS (Animate On Scroll) for animations
- Custom lightbox for the diet gallery

## 📌 Main Features

- Navigation menu with scroll to sections.
- Hero section with image slideshow.
- Diet section with image lightbox.
- Tabs system to explain types of consultations.
- Client reviews section with images and client names.
- Contact form with:
  - Required field validation.
  - Format validation "Weight (kg) / Age / Height (cm)".
  - Confirmation modal with appointment summary.
- Direct WhatsApp link and social media icons.

## 🚀 How to View It

1. Clone the repository or download the files.
2. Open the `index.html` file in your browser.

## ✅ Best Practices Applied

- Use of descriptive alt attributes on all images.
- `lang="es"` attribute in the `<html>` tag.
- Accessible labels hidden using the `.sr-only` class.
- Clear and semantic navigation.
- Separation of responsibilities:
    - HTML → structure
    - CSS → styles
    - JavaScript → behavior

## 📚 Future Improvements (Ideas)

- Connect the contact form to a real backend to send the data.
- Add more visual states (hover/focus) for buttons and links.
- Further improve responsive design for specific tablet sizes.

## Functionality

- Convert client reviews into an interactive card system.
- Simulate a more realistic WhatsApp conversation (time, avatar, chat bubble).
- Add smooth animations when opening and closing modals.
- More advanced form validation with custom messages.

## 🛠 Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript (vanilla)
- Google Fonts
- AOS (Animate On Scroll) para animaciones

- Hero con slideshow de imágenes.
